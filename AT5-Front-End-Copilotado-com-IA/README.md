 # 🎬 Inteligencia Artificial Como Colega de Trabalho
## 📝 Sobre
 Este site fala sobre o tema como seria o seu companheiro como IA.
 Onde o site consiste como responder as perguntas e tirar dúvidas 
 das pessoas sobre esse tema. Explicando sobre sua história e evolução.
## 🚀 Ferramentas Utilizadas
* **Linguagem:** HTML5 e CSS
* **Bibliotecas:** Bootstrap
* **Ferramentas:** VSCode
* **Modelo de IA:** Chatgpt
## 📊 Construção e Resultado
 Resultados: A gente desenvolveu os códigos, os separamos em grupos, e colocamos
 seus prompts em seleção, separado seus códigos, colocando suas tags para ir para 
 as outras páginas, que por fim, fizemos a análise se teve erros ou falhas nos códigos.
 Aprendizados: Aprendemos a modular melhor o site, desenvolve-lo usado o bootstrap,
 usado exemplos já dando nas aulas para implementar no site, e usado varios códigos
 num único fechamento de códigos de uma página.
## 🧠 Uso de IA
 Usamos Inteligencoa Artificial. (Chatgpt) usado na introdução dos códigos do html,
 nas seleções de grupos dos códigos, na parte principal do site, nas tags e botões,
 e sendo usado na análise e observação do site,verifição para saber se timha algun código
 não funcionado ou incorretos.
